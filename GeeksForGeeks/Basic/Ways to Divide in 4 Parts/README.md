<h2><a href="https://www.geeksforgeeks.org/problems/divide-the-number5320/1">Ways to Divide in 4 Parts</a></h2><h3>Difficulty Level: Basic</h3><hr><p><span style="font-size: 18px;">Given a positive integer <strong>n</strong>, count the number of ways to represent <strong>n</strong> as the sum of four positive integers.</span></p>
<ul>
<li><span style="font-size: 18px;">In each representation: </span><span style="font-size: 18px;">a + b + c + d = n</span></li>
<li><span style="font-size: 18px;">where: </span><span style="font-size: 18px;">a &gt; 0, b &gt; 0, c &gt; 0, d &gt; 0</span></li>
</ul>
<p><span style="font-size: 18px;">Return the total number of such representations.</span></p>
<p><span style="font-size: 18px;"><strong>Examples:</strong></span></p>
<pre><span style="font-size: 18px;"><span style="font-size: 18px;"><strong>Input: </strong>n = 5<strong>
Output: </strong>1<strong>
Explanation: </strong>The only possible representation is: 1 + 1 + 1 + 2 = 5. Therefore, the answer is 1.</span></span></pre>
<pre><span style="font-size: 18px;"><strong>Input: </strong>n = 41<strong>
Output: </strong>511<strong>
Explanation: </strong>There are 511 different ways to represent 41 as the sum of four positive integers. Therefore, the answer is 511.</span></pre>
<p><span style="font-size: 18px;"><strong>Constraints:</strong><br>0 ≤ n ≤ 100</span></p>
